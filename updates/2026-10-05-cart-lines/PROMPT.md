Нужно перенести обновление фронтенда Frito «один товар с разными модификаторами — отдельные строки корзины» в наш рабочий проект.

Материалы лежат в папке `updates/2026-10-05-cart-lines/`:
- `README.md` — что и зачем поменялось, новый формат данных, требования к API, сценарий проверки. **Прочитай полностью.**
- `cart-lines.patch` — патч относительно исходной передачи (коммит `3d8d1e1`).

Порядок работы:
1. Сначала проверь, применяется ли патч без конфликтов: `git apply --check updates/2026-10-05-cart-lines/cart-lines.patch`.
   - Если применяется — примени и переходи к шагу 3.
   - Если нет (мы уже меняли эти файлы под API) — **не перезаписывай наши правки**. Перенеси смысл изменений вручную, файл за файлом, по таблице «Файлы» в README.
2. Суть изменения, которое нужно сохранить при ручном переносе:
   - корзина хранится по **ключу строки** `lineKey(productId, selectedOptions)`, а не по id товара; одинаковый состав складывается, разный — отдельные строки;
   - `mods`, `extra`, `sels` — тоже по ключу строки; каталог, стоп-лист и аналитика — по id товара через `pid(key)`;
   - правка строки с изменением состава меняет её ключ, а при совпадении с другой строкой строки сливаются;
   - «+» на карточке товара с модификаторами открывает окно выбора; «−» при нескольких вариантах открывает корзину (мобайл) или показывает подсказку (ПК);
   - подсказка `inCartNote` в `FritoProductModal`;
   - строки с модификаторами доходят до оформления, страницы заказа и «Повторить».
3. Бэкенд: по разделу «Что сделать на бэкенде» в README проверь, что `POST /orders` принимает строки с `options` по отдельности, сервер считает цену и хранит снимок опций, а история и `GET /orders/:no` отдают опции для повтора. Если что-то не так — предложи изменения и покажи мне до того, как вносить.
4. Не меняй дизайн и тексты сверх патча. Цвета — только токены из `frito.css`. Новые тексты — с переводом в `frito-i18n-kk.js` (или в наш словарь, если i18n уже переделан). Правила проекта — в `AGENTS.md`.
5. Проверь в браузере по сценарию «Как проверить» из README: 375 px и 1280 px, русский и казахский. Покажи мне результат: какие файлы изменены, что проверено, что не получилось.
