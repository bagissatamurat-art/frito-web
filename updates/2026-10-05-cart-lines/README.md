# Обновление 2026-10-05 — один товар с разными модификаторами

**Коротко.** Раньше корзина хранила одну строку на товар. Если клиент брал второй «Сеул бокс» с другими модификаторами (острый вместо неострого), первая строка затиралась. Теперь **строка корзины — это товар вместе с набором модификаторов**: разный состав даёт разные строки, одинаковый состав складывается в одну.

- Базовая версия: коммит `3d8d1e1`, то есть то, что уже на проде.
- Новая версия: коммит `96c52f4`.
- Патч: [`cart-lines.patch`](cart-lines.patch), применяется командой `git am` или `git apply`.

## Что видит клиент

| Где | Было | Стало |
|---|---|---|
| Корзина | одна строка «Сеул бокс», выбор нового состава затирал старый | две строки, у каждой свой состав, цена и количество |
| Тот же состав ещё раз | — | +1 к существующей строке, новая не создаётся |
| «Изменить» в строке | меняла общий состав товара | меняет только эту строку; если состав совпал с другой строкой, они объединяются |
| «+» на карточке товара с модификаторами | +1 к единственной строке | открывает окно выбора, чтобы собрать новый вариант |
| «−» на карточке | −1 | один вариант — −1; несколько вариантов — на телефоне открывается корзина, на ПК подсказка «Выберите вариант в корзине» |
| Окно товара, если он уже в корзине | — | подсказка над кнопкой: «В корзине уже N шт. Другой состав — отдельной строкой, такой же — добавим к ней» |
| Оформление, страница заказа, «Повторить» | состав одной строки на товар | каждая строка со своими модификаторами |

## Ключ строки

```js
// menu.dc.html
lineKey('seul-box', { 'spice-b': ['hot'], drink: ['cola'] })   // → "seul-box~drink:cola;spice-b:hot"
lineKey('cola')                                                // → "cola" (товар без модификаторов)
pid('seul-box~drink:cola;spice-b:hot')                        // → "seul-box" (id товара из ключа)
```

Группы и опции сортируются, поэтому порядок выбора на ключ не влияет. Пустые группы в ключ не попадают.
Состояние меню (`cart`, `mods`, `extra`, `sels`) теперь хранится **по ключу строки**, а не по id товара. Каталог, стоп-лист и аналитика по-прежнему работают с id товара через `pid(key)`.

## Изменения формата данных

| Ключ localStorage | Было | Стало |
|---|---|---|
| `frito_cart.items[]` | `{id, qty, mods, extra}` | `{id, key, qty, mods, extra, sel}` — одна запись на **строку** |
| `frito_orders[].items[]` | `[id, qty]` | `[id, qty, {key, mods, extra, sel, price}]` |
| `frito_view` | `{…, items, repeat:{id:qty}}` | `{…, items, repeat:{key:qty}, repeatMeta:{key:{mods,extra,sel}}}` |
| `frito_repeat` | `{items:{id:qty}, at}` | `{items:{key:qty}, meta:{key:{mods,extra,sel}}, at}` |

**Совместимость.** Старые записи читаются как раньше: третий элемент заказа необязателен, `key` по умолчанию равен `id`. Миграция не нужна.

## Что сделать на бэкенде

1. `POST /orders` — передавать **каждую строку отдельно**: `{ productId, qty, options: [optionId, …] }`. Не группировать по `productId`.
2. Сервер считает цену строки (база + опции) и сохраняет в позиции заказа **снимок** выбранных опций (названия и цены на момент заказа).
3. Строки с одинаковым `productId` и одинаковым набором опций можно склеить.
4. `GET /orders/:no` и история заказов должны отдавать позиции с опциями, чтобы «Повторить» восстановил варианты: `items: [{ productId, qty, options, optionsText, price }]`.
5. Если корзина хранится на сервере, ключ строки = `productId` + отсортированный набор `optionId`, как в `lineKey`.

## Как проверить (5 минут)

1. Главная → «Сеул бокс» → «В корзину» с настройками по умолчанию.
2. Снова «Сеул бокс». Над кнопкой видна подсказка «В корзине уже 1 шт.». Выбрать «Острый» → «В корзину». В корзине **две строки**.
3. Ещё раз добавить острый вариант: количество второй строки = 2, новой строки нет.
4. «Изменить» во второй строке → «Неострый» → «Сохранить»: строки объединились, количество 3.
5. «−» на карточке при двух вариантах: на телефоне открывается корзина, на ПК — подсказка.
6. Оформление → оплата → страница заказа: обе строки со своими модификаторами. «Повторить» восстанавливает обе строки.
7. То же на 375 px и на казахском.
