# Frito — чек-лист запуска на frito.kz

Отмечайте по ходу. Всё, что зависит от бэкенда, описано в [BACKEND.md](BACKEND.md).

## 1. Домен и адреса
- [ ] Сайт отдаётся с корня `https://frito.kz/` по HTTPS. Редирект `www` → без `www`, `http` → `https`.
- [ ] **Чистые адреса** (рекомендуется): `/` → `menu.dc.html`, `/vacancies`, `/delivery`, `/franchise`… через rewrite на сервере. Если меняете адреса, обновите ссылки в шапке, футере и меню, а в `tools/seo.py` — `PAGES` и `BASE`.
- [ ] **301-редиректы со старого сайта.** Соберите список URL старой версии (меню, категории, товары, контакты, вакансии) и перенаправьте каждый на ближайшую новую страницу. Иначе сайт потеряет позиции в поиске.
- [ ] Страница 404: в `404.html` поменять `<base href="/frito-web/">` на `<base href="/">` и настроить сервер отдавать её с кодом 404.
- [ ] `index.html` сейчас — мгновенный редирект на `menu.dc.html`. При чистых адресах главную лучше отдавать прямо на `/`.

## 2. SEO
- [ ] В `tools/seo.py`: `BASE = 'https://frito.kz/'` (или новый адрес), `VERIFY` — коды Google Search Console и Яндекс.Вебмастера. Затем `python3 tools/seo.py`.
- [ ] `robots.txt` начнёт работать только в корне домена. Проверьте, что `account`, `checkout` и `tools` закрыты.
- [ ] Отправить `sitemap.xml` в Search Console и Вебмастер.
- [ ] Проверить разметку: Rich Results Test (меню и рестораны на главной, вакансии на `vacancies`).
- [ ] После перехода на API Schema.org-данные меню и вакансий должны генерироваться из БД (сейчас `tools/seo.py` берёт их из кода).
- [ ] Желательно: SSR или пререндер. Страницы рисуются JavaScript'ом, Яндекс такое индексирует хуже. Для страниц без JS уже есть `<noscript>` с меню.
- [ ] Казахская версия сейчас без отдельных адресов и не индексируется. Если нужен поиск на казахском — `/kk/…` + `hreflang`.

## 3. Ключи и интеграции
- [ ] **Mapbox:** токен ограничить доменом frito.kz. Лучше вынести в конфиг.
- [ ] **DaData:** публичный ключ ограничить доменом. Секретный ключ — только на сервере (лучше проксировать запросы через бэк).
- [ ] **Telegram-бот** `@FritoKzBot`: настоящий бот для входа. Имя бота задаётся в `frito.js → FritoContacts.telegramBot`. Перегенерировать QR `assets/qr-tg-login.svg` (или генерировать на клиенте по `botUrl`).
- [ ] **Kaspi** (счёт по номеру) и **эквайринг** для карт — договоры, ключи, webhook об оплате.
- [ ] **WhatsApp** для кодов входа: WhatsApp Business API или провайдер.

## 4. Аналитика
- [ ] `analytics.js → CFG`: `gtm`, `ga4`, `ym`, `fbPixel`. Если GA4 и Pixel настроены внутри GTM — оставить их пустыми.
- [ ] Метрика: цели по событиям `add_to_cart`, `begin_checkout`, `purchase`, `generate_lead`, `contact`. Электронная коммерция уже передаётся через `dataLayer`.
- [ ] `purchase` должен получать настоящий `orderNo` с сервера (сейчас — случайный).
- [ ] Баннер cookie: `requireConsent: true` — счётчики работают только после согласия. Решите юридически, оставить ли так.

## 5. Контент и юридическое
- [ ] Реквизиты в оферте и политике: `[наименование юрлица]`, `[БИН]`, `[адрес]`, `[дата]`. Тексты генерирует `tools/legal.py`: положите реквизиты в `tools/req.json` (`{name, bin, addr, bank:[…], date}`) и запустите `python3 tools/legal.py && python3 tools/seo.py`. Тексты должен проверить юрист.
- [ ] Оферта и политика на казахском — нужен профессиональный перевод.
- [ ] Рестораны вне Астаны в окне адреса — **демо**. Удалить или заменить реальными. Тексты про «5 городов» на странице доставки — тоже.
- [ ] Стоимость доставки, время, «бесплатно от 8 000 ₸», сроки ответа на заявки, условия франшизы и помещений — сверить с реальностью.
- [ ] Фото на страницах франшизы, поставщиков и помещений (`assets/partners/`) сгенерированы ИИ — заменить реальными, когда будут.
- [ ] Вакансии в `frito-data.js` — черновик HR, нужно из БД.
- [ ] Шрифт **Transforma** (гайдлайн) — купить лицензию, подключить `@font-face`. Сейчас подставляется Montserrat.

## 6. Производительность
- [ ] **Картинки товаров**: отдавать уменьшенные копии (480 и 960 px, WebP/AVIF) + `srcset`. Сейчас 1600×900 по ~380 КБ — главный тормоз (см. AUDIT).
- [ ] Кэш на сервере: `*.css`, `*.js`, `assets/*` — долгий кэш с версионированием имён; `*.html` — короткий.
- [ ] HTTP/2 или 3, Brotli/gzip.
- [ ] Шрифты: при подключении Transforma — `woff2`, `font-display: swap`, `preload` для одного начертания.

## 7. Финальная проверка
- [ ] Сценарий на телефоне и ПК: меню → товар с модификаторами → адрес → корзина → вход → оформление → оплата Kaspi и картой → статус → кабинет → повтор → оценка.
- [ ] Ошибки: товар закончился, адрес вне зоны, неверный код, оплата не прошла, отмена.
- [ ] Казахский: пройти те же экраны с «Қаз».
- [ ] Lighthouse (мобайл) на главной: LCP < 2,5 с, CLS < 0,1.
